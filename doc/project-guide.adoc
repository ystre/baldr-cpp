= Project Guide

This document describes how to use the repository in more details.

== Pre-requisites

* Baldr itself (it cannot bootstrap itself)
* CMake
* GCC
* Conan and `~/conan_provider.cmake`
* Makeself

== Useful Commands

Build Baldr with full static linking for usage in any Docker image.

[source,shell]
----
baldr build -b Release -DBALDR_STATIC_LINK=ON
----

== Coding Guidelines

* Apply https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines[C++ Core Guidelines].
* Functions should have minimal scope (SRP, Single Responsibility Principle)
** Use concise function documentation, avoid assuming knowledge about outer layers.
* Rely on link:../deps/nova-cpp/libnova/libnova/[Nova] for generic C++ abstractions.
** Especially for error handling.

== Testing Guidelines

* All functions that do not rely on system calls or other processes should be
  unit-tested.
** Otherwise their functionality should be tested by link:../tests[system
   tests].
