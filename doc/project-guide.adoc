= Project Guide

This document describes how to use the repository in more details.

== Pre-requisites

* Baldr itself (it cannot bootstrap itself)
* CMake
* GCC
* Conan and `~/conan_provider.cmake`
* Makeself

== Useful Commands

Build Baldr with full static linking for usage in any Docker image.

[source,shell]
----
baldr build -b Release -DBALDR_STATIC_LINK=ON
----

== Coding Guidelines

* Apply https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines[C++ Core Guidelines].
* Functions should have minimal scope (SRP, Single Responsibility Principle)
** Use concise function documentation, avoid assuming knowledge about outer layers.
* Rely on link:../deps/nova-cpp/libnova/libnova/[Nova] for generic C++ abstractions.
** Especially for error handling.

== Testing Guidelines

* All functions that do not rely on system calls or other processes should be
  unit-tested.
** Otherwise their functionality should be tested by link:../tests[system
   tests].

== File Headers

Every C++ source file starts with a header block containing some metadata and
describing the functionality.

[source,cpp]
----
/**
 * Part of Baldr
 *
 * @brief   One-sentence summary, which may continue on further lines,
 *          aligned with its first line.
 *
 * Optional details.
 *
 * @author      Name
 * @coauthor    Name
 * @created     2026-08-11
 * @updated     2026-11-06
 * @status      evolving
 * @reviewed    skimmed
 * SPDX-License-Identifier: BSL-1.0
 *
 * Optional free text.
 */
----

=== Status and Review

`@status` says how mature the code is, `@reviewed` how closely it was read:
`none`, `skimmed`, `read` or `audited`.

[cols="1,3"]
|===
| `@status` | Requires

| `experimental`
| Nothing. The default of new files.

| `evolving`
| Nothing.

| `stable`
| `@reviewed read` or better, a sibling `*.test.cpp` reviewed `read` or better, and
no `TODO` or `FIXME`.

| `frozen`
| As `stable`, but `@reviewed audited`. No changed expected other than fixes.

| `deprecated <replacement>`
| The path of the replacement, which must exist.
|===

Status is not needed for `main`, for tests and examples.
