= Baldr Test Specification

== Test suites

The script `run.sh` is the runner for all test suites.

=== Classifier rules

**Tool**: `classifier-check`, built from `classifier-check.cpp`

**Description**: Checks the shipped `res/classifier.toml` against the lines of
known level in `classifier-lines.txt`, without running Baldr. A new marker in the
rules gets a line there. The classifier's logic has unit tests with rules of
their own, so they don't depend on the shipped file.

=== Smoke tests

**Script**: `smoke.sh`

**Description**: Calls Baldr with various CLI arguments smoke testing features.

=== Config files

**Script**: `config.sh`

**Description**: Runs a copy of the CMake test project with config files in
every format, in the project and in a fake `$HOME`, checking that each is
found, that the two merge whatever their formats, that a deleted define leaves
an existing build directory, and that a broken setup (several config files in
one directory, an inaccessible directory, malformed or wrongly typed content)
fails with a clear error.

=== Building in Docker image

**Script**: `glibc.sh`

**Description**: Builds a Docker image (`glibc.Dockerfile`) with an older GLIBC
version and uses that image to build a test project. The built target can be
run on the host natively.

=== Statically linking Baldr

**Script**: `static-link.sh`

**Description**: Builds and statically links Baldr, packages into an alpine
image and runs Baldr (calling `--version`).
